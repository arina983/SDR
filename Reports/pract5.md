## Практика 5

### 1. Цель работы

Настроить два SDR-устройства ADALM-PLUTO (подключены одновременно) для организации передачи сигнала с одного Pluto на другой: один работает на приём (RX), второй — на передачу (TX).

### Выполнение работы
При выполнении работы я столкнулась с несколькими проблемами: 

Проблема 1: ERROR: Bad URI: 'usb:' + no device context found.

Причина: сокращённый URI usb: работает только при одном устройстве. При двух нужен уникальный адрес.

Решение: стала использовать уникальные URI — usb:1.2.5 и usb:1.3.5 (получены из iio_info -s). Позже выяснилось, что адреса меняются при переподключении, поэтому рекомендуется использовать серийные номера.

Проблема 2: ./main 1 0 выдавал «не удалось открыть устройство», хотя lsusb показывал оба Pluto.

Причина: программа использовала жёстко заданный URI usb:, который при двух одновременно подключённых устройствах неоднозначен.
