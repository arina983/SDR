## 2. Исследование радиочастотного спектра с помощью GNU Radio и PlutoSDR


### 1. Цель работы

Ознакомиться с возможностями GNU Radio Companion по визуализации радиочастотного спектра в реальном времени с использованием SDR-устройства ADALM-Pluto. Научиться настраивать приёмник на заданную частоту, отображать спектр мощности (Frequency Sink) и водопадную диаграмму (Waterfall Sink), а также идентифицировать источники сигнала по изменению спектральной картины.

---

### 2. Используемое оборудование и программное обеспечение

- SDR-приёмник **ADALM-Pluto**
- GNU Radio Companion (QT GUI)
- Ноутбук с динамиками или наушниками
- Источник сигнала: раздача мобильного интернета с телефона на ноутбук (трафик в эфире)

---

### 3. Описание схемы

В GNU Radio Companion была собрана простая схема анализатора спектра:

**Блоки и параметры:**

| Блок                        | Назначение                              | Параметры                                      |
|-----------------------------|-----------------------------------------|------------------------------------------------|
| **Options**                 | Настройки проекта                       | Title: Not titled yet<br><br>Output Language: Python<br>Generate Options: QT GUI |
| **Variable** (`samp_rate`)  | Частота дискретизации                   | 5 МГц                                          |
| **Variable** (`cent_freq`)  | Центральная частота                     | 658 МГц                                        |
| **PlutoSDR Source**         | Приём IQ-сигнала                        | IIO context URI: (по умолчанию)<br>LO Frequency: 658 МГц<br>Sample Rate: 5 МГц<br>Buffer size: 32.768k<br>Quadrature: True<br>RF DC Correction: True<br>BB DC Correction: True<br>Gain Mode (RX1): Slow Attack<br>Filter Configuration: Auto<br>RF Bandwidth: 20 МГц |
| **QT GUI Frequency Sink**   | Отображение спектральной плотности мощности | FFT Size: 1024<br>Center Frequency: 658 МГц<br>Bandwidth: 5 МГц |
| **QT GUI Waterfall Sink**   | Водопадная диаграмма (спектр во времени) | FFT Size: 1024<br>Center Frequency: 658 МГц<br>Bandwidth: 5 МГц |

**Структура схемы:**  
PlutoSDR Source → разветвление на  
- QT GUI Frequency Sink  
- QT GUI Waterfall Sink  

Схема предназначена для наблюдения эфира в полосе ±2.5 МГц относительно центральной частоты 658 МГц.

### 4. Результаты работы

#### 4.1. Настройка частоты

Центральная частота приёмника была установлена на **658 МГц**.  
Данный диапазон выбран, так как при раздаче мобильного интернета с телефона на ноутбук в эфире появлялся заметный трафик (активность сигнала).

#### 4.2. Анализ полученных графиков

**Водопадная диаграмма (верхний график):**
- По оси X — частота (от ~655.5 до ~660.5 МГц)
- По оси Y — время (от 0 до 20 с)
- Яркие горизонтальные линии и полосы оранжево-жёлтого цвета указывают на наличие сигнала.
- Отчётливо видна активность в районе **658.205 МГц** (отмечена на графике), что соответствует частоте канала, используемого устройством при раздаче интернета.
- Сигнал имеет прерывистый характер — типично для пакетной передачи данных (трафик).

**Спектр мощности (нижний график):**
- Уровень сигнала колеблется в диапазоне примерно от −50 до −90 дБ.
- Наблюдаются множественные пики по всей полосе обзора, что характерно для шумового фона + полезного сигнала передачи данных.
- Наиболее выраженная активность сосредоточена вблизи центральной частоты 658 МГц.

#### 4.3. Идентификация источника

При включении раздачи интернета с телефона на ноутбук на водопаде и спектре появлялась заметная активность.  
По частоте максимума активности была определена рабочая частота канала — **≈ 658.2 МГц**.
