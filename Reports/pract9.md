## 1. Цель этапа

Реализовать символьную синхронизация для QPSK / BPSK

## 2. Назначение модуля

Модуль `timing_sync` решает задачу **символьной синхронизации** - определения моментов времени, в которые нужно брать отсчёты принятого сигнала, чтобы получить корректные QPSK/BPSK-символы.


---

## 3. Реализация

В файле `timing_sync.c` реализована символьная синхронизация.

```c
typedef struct {
    int L; // отсчётов на символ 
    float tau_s; // текущее смещение tau_s 
    float err_avg; // усреднённая ошибка после фильтра
    float alpha; // коэффициент фильтра ошибки (0..1)
    float step; // шаг коррекции tau_s
} TimingSync;
```


Для каждого отсчёта вычисляется сумма последних L значений отдельно
для составляющих I и Q:
```c
out[n] = in[n-L+1] + ... + in[n]
```
Первые L-1 выходных отсчётов заполняются нулями, поскольку для них
недостаточно входных данных.

Фильтрация позволяет объединить вклад отсчётов, относящихся к одному
символьному интервалу.

### Оценка временной ошибки
В функции `timing_sync_step()` используется три соседних отсчёта
отфильтрованного сигнала:
- x0 - предыдущий отсчёт;
- x1 - центральный отсчёт;
- x2 - следующий отсчёт.

По ним вычисляется ошибка временной синхронизации:
```cpp
float e = x1_i * (x0_i - x2_i) + x1_q * (x0_q - x2_q);
```
Значение ошибки сглаживается с помощью экспоненциального фильтра:
```cpp 
ts->err_avg = (1.0f - ts->alpha) * ts->err_avg + ts->alpha * e;
```
Это позволяет уменьшить влияние отдельных резких изменений ошибки.
### Коррекция момента выборки
Для корректировки используется накопитель `tau_s`.

В зависимости от знака усреднённой ошибки значение tau_s увеличивается
или уменьшается на величину `step`.

Когда накопленное смещение достигает одного отсчёта, изменяется индекс
выборки n:
- при `tau_s >= 1` индекс увеличивается;
- при `tau_s <= -1` индекс уменьшается.

После коррекции из центрального положения окна выбирается символ:
```cpp
sym->I = x1_i;
sym->Q = x1_q;
```
Следующий момент обработки устанавливается с шагом L отсчётов.
### Объединение алгоритма синхронизации
Для объединения всех операций создана функция `timing_sync_process()`.

Она выполняет следующие действия:
1. выделяет память под отфильтрованный сигнал;
2. вызывает matched_filter();
3. последовательно обрабатывает сигнал функцией timing_sync_step();
4. сохраняет полученные символы в выходной массив;
5. освобождает выделенную память.

В `main.cpp` алгоритм вызывается одной строкой:
```cpp
int n_sym = timing_sync_process(&ts, rx_cpx, sr, syms, sr / L + 5);
```

Полученные символы записываются в `qpsk_symbols.txt`.

## 4. Текущая реализация 

```
TX:
bits → QPSK → rectangular(L) → int16 I/Q
                              ↓
                         writeStream()
                              ↓
                            Эфир
                              ↓
RX:
readStream() → int16 I/Q → Complex
                              ↓
                         matched_filter()
                              ↓
                       timing_sync_step()
                              ↓
                    оценка временной ошибки
                              ↓
                     коррекция tau_s и idx
                              ↓
                       выбор символов
                              ↓
                       qpsk_symbols.txt
                              ↓
                     Python / ImGui
```
