## 1. GNU Radio. Построение радио-приёмника


### 1. Цель работы

Ознакомиться с инструментарием GNU Radio, научиться строить конфигурацию программного радиоприёмника FM-сигнала с использованием SDR-устройства ADALM-Pluto (PlutoSDR) и провести приём реальной радиостанции.

---

### 2. Используемое оборудование и программное обеспечение

- SDR-приёмник **ADALM-Pluto** (IIO context URI: `192.168.3.1`)
- GNU Radio Companion
- Операционная система Windows
- Акустическая система / наушники компьютера

---

### 3. Описание схемы

В GNU Radio Companion была построена следующая схема приёмника широковещательного FM-сигнала:

**Основные блоки:**

| Блок                    | Назначение                                      | Основные параметры                          |
|-------------------------|-------------------------------------------------|---------------------------------------------|
| **PlutoSDR Source**     | Приём сигнала с SDR-устройства                  | LO Frequency = 99 МГц<br>Sample Rate = 2.4 МГц<br>RF Bandwidth = 20 МГц |
| **Variable**            | Частота дискретизации                           | `samp_rate` = 2.4 МГц                       |
| **QT GUI Range**        | Тонкая подстройка частоты несущей               | ID: `tune`<br>Диапазон: 80–110 МГц<br>Шаг: 100 кГц |
| **Low Pass Filter**     | Фильтрация и понижение частоты дискретизации    | Decimation = 5<br>Cutoff Freq = 100 кГц<br>Transition Width = 50 кГц<br>Window = Hamming |
| **WBFM Receive**        | Демодуляция широкополосного FM-сигнала          | Quadrature Rate = 480 кГц<br>Audio Decimation = 10 |
| **QT GUI Frequency Sink** (несколько) | Отображение спектра на разных этапах обработки | FFT Size = 1024                             |
| **QT GUI Time Sink**    | Отображение сигнала во временной области        | Number of Points = 1024<br>Sample Rate = 480 кГц |
| **Audio Sink**          | Вывод звука на динамики                         | Sample Rate = 48 кГц                        |

**Структура обработки сигнала:**

1. PlutoSDR Source → приём IQ-сигнала на частоте ~99 МГц с частотой дискретизации 2.4 МГц.
2. Сигнал разветвляется:
   - На QT GUI Frequency Sink (широкополосный спектр, 2.4 МГц).
   - На Low Pass Filter (фильтрация + децимация в 5 раз → 480 кГц).
3. После фильтра:
   - QT GUI Frequency Sink (спектр полосы 480 кГц).
   - QT GUI Time Sink.
   - WBFM Receive (демодуляция + децимация до 48 кГц).
4. С выхода WBFM Receive:
   - QT GUI Frequency Sink (аудио-спектр).
   - Audio Sink (прослушивание).

### 4. Результаты работы

#### 4.1. Настройка и поиск станции

С помощью слайдера `tune` (QT GUI Range) была найдена действующая FM-радиостанция на частоте **99.1 МГц**.

На широкополосном спектре (до фильтра) наблюдался характерный «холм» сигнала станции шириной около 200 кГц.

#### 4.2. Спектральные характеристики

- **Верхний график (Time Sink):** сигнал во временной области после фильтрации — амплитуда близка к нулю с небольшими флуктуациями.
- **Средний график (Frequency Sink после LPF):** спектр в полосе ±240 кГц. Виден полезный сигнал в центре с уровнем примерно −40…−50 дБ относительно максимума.
- **Нижний график (Frequency Sink после демодуляции):** спектр аудиосигнала. Основная энергия сосредоточена в области низких частот (речь и музыка), что соответствует реальному радиовещанию.

#### 4.3. Аудиовоспроизведение

После настройки частоты и параметров децимации на выходе Audio Sink появился разборчивый звук радиостанции (речь диктора / музыка). Приём устойчивый, без сильных искажений.
