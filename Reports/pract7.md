## Практика 7

### 1. Цель работы

Реализовать цепочку цифрового передатчика:

1. Генератор битов  
2. Модуляция (BPSK / QPSK) → комплексные символы  
3. Формирование прямоугольных импульсов 
4. Передача через PlutoSDR и приём на втором PlutoSDR  

---

## 2. Что было сделано

### 2.1. Программа SoapySDR

- Открытие Pluto по URI (`usb:…`)
- Настройка sample rate (1 МГц), частот RX/TX, усилений
- RX-поток всегда, TX-поток только в режиме `tx`
- Запись принятых данных в `sdrX_rxdata.pcm` (int16, I/Q)
- Режим запуска: `./main sdr1|sdr2 rx|tx <uri>`

### 2.2. Модуль передатчика (`transmitter.h`)

| Функция | Назначение |
|---------|------------|
| `generate_bits` | Случайные биты 0/1 |
| `bpsk` | 1 бит → символ ±1 + j0 |
| `qpsk` | 2 бита → символ (±1 ± j) |
| `upsample` | Вставка нулей между символами |
| `rectangular` | Каждый символ растягивается на L отсчётов (прямоугольные импульсы) |



### 2.3. Параметры эфира

- **Частоты** (крест-накрест):
  - sdr1: TX **700 МГц**, RX 790 МГц  
  - sdr2: RX **700 МГц**, TX 790 МГц  
- Sample rate: **1 МГц**  
- TX_GAIN ≈ 40…60, RX_GAIN ≈ 50…60  
- Амплитуда цифрового сигнала: ×20000  
- L (длина символа в сэмплах): 64 (для наглядности)

## 3. Что получили

### 3.1. Программная часть

- Рабочая цепочка биты → QPSK → прямоугольные импульсы → эфир
- Приём в PCM-файл и просмотр в Python (`graph.py`)
- Два Pluto на одном ПК, разные URI

### 3.2. Результаты в эфире

| Этап | max\|I\|, max\|Q\| | 
|------|-------------------|
| Начало | ≈ 4 | Только шум |
| После настройки частот/gain |  ≈ 90 
| После усиления и сближения антенн | 2048

На графиках:

- До пакета - слабый фон  
- Во время передачи - мощный участок с амплитудой до ±2048  
- При увеличении масштаба видны площадки I/Q (прямоугольная огибающая), искажённые фильтрами Pluto
