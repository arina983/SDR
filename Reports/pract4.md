### 3. Описание программы

Программа `main.cpp` реализует взаимодействие с ADALM-Pluto через SoapySDR. Режим работы задаётся аргументами командной строки:

```bash
./main <rx> <tx>
```

где:

- `rx = 1` — включить приёмник, `0` — выключить;
- `tx = 1` — включить передатчик, `0` — выключить.

Примеры запуска:

```bash
./main 1 0    # только приём
./main 0 1    # только передача
./main 1 1    # приём + передача
```

#### 3.1. Инициализация устройства

| Ключ              | Значение   | Назначение                  |
|-------------------|------------|-----------------------------|
| `driver`          | `plutosdr` | драйвер PlutoSDR            |
| `uri`             | `usb:`     | подключение по USB          |
| `direct`          | `1`        | прямой доступ через DMA     |
| `timestamp_every` | `1920`     | период timestamp-меток      |
| `loopback`        | `0`        | внутренняя петля выключена  |

#### 3.2. Настройка параметров RX и TX

Для каждого включённого направления задаются:

```c
double sample_rate  = 1e6;    // 1 MSPS
double carrier_freq = 800e6;  // 800 МГц
```

- частота дискретизации — **1 MSPS**;
- несущая частота — **800 МГц**;
- усиление RX — **10.0 дБ**;
- усиление TX — **-90.0 дБ** (близко к минимуму).

#### 3.3. Создание потоков

Для каждого направления создаётся поток в формате `SOAPY_SDR_CS16` (Complex Signed 16-bit, I и Q по 2 байта):

```c
rxStream = SoapySDRDevice_setupStream(sdr, SOAPY_SDR_RX, SOAPY_SDR_CS16,
                                      channels, channel_count, NULL);
SoapySDRDevice_activateStream(sdr, rxStream, 0, 0, 0);
```

Аналогично для TX. Используется один канал (индекс `0`).

#### 3.4. Буферы и MTU

Размер буфера определяется через `SoapySDRDevice_getStreamMTU`. Буфер выделяется динамически:

```c
rx_buffer = (int16_t*)malloc(sizeof(int16_t) * 2 * rx_mtu);
tx_buff   = (int16_t*)malloc(sizeof(int16_t) * 2 * tx_mtu);
```

Множитель `2` — потому что каждый сэмпл содержит компоненты I и Q.

#### 3.5. Основной цикл приёма

На каждой из 40 итераций выполняется `SoapySDRDevice_readStream`. Полученные сэмплы сохраняются в файл `rxdata.pcm` в бинарном виде. Выводится лог:

```text
Buffer  N | Samples: S | Flags: F | Time: T | Diff: D нс
```

где `Time` — временная метка первого сэмпла буфера, а `Diff` — разница с предыдущей меткой.

#### 3.6. Передача с временной меткой

На третьей итерации формируется и отправляется тестовый сигнал:

```c
long long tx_time = timeNs + (4 * 1000 * 1000); // +4 мс
```

В начало TX-буфера записывается служебный заголовок:

- маркеры `0xffff` в позициях 0–1 и 10–11;
- 8 байт времени `tx_time` в позициях 2–9 (побайтово, со сдвигом `<< 4`).

Отправка выполняется с флагом `SOAPY_SDR_HAS_TIME`:

```c
flags = SOAPY_SDR_HAS_TIME;
SoapySDRDevice_writeStream(sdr, txStream, tx_buffs, tx_mtu,
                           &flags, tx_time, timeoutUs);
```

#### 3.7. Завершение работы

Корректно освобождаются ресурсы в обратном порядке:

1. `fclose(file)`;
2. `SoapySDRDevice_deactivateStream` + `closeStream` для RX и TX;
3. `free(rx_buffer)`, `free(tx_buff)`;
4. `SoapySDRDevice_unmake(sdr)`.
